# Nimue — Hack Brasil 2026

Original competition demonstration, all identities and data synthetic. No production system or real student information. The application is a serverless school demo: six students, twelve guardians, four teachers, three administration roles; evidence-based gap suggestions; personalized practice; teacher-approved intervention; feedback, guardian communication and aggregate reporting.

Local automated test: `node --test worker.test.mjs` (Node 22+). The memory adapter is for tests only. Production demo adapter uses Cloudflare D1; create a dedicated database, apply `schema.sql`, bind it as `DB`, and deploy module `worker.mjs` to a new challenge-only Worker. No account identifiers or credentials belong in source control. The demo uses a browser-specific opaque run cookie. Deliberate synthetic role selection is exposed for judging; it is not a production identity provider. Server-side role filters and mutation authorization are tested. Recommendations are deterministic formative rules, not a live generative-AI model. No OpenAI credentials are configured in this public repository.

Demonstration path: enter as S1 and submit a wrong answer, send student feedback; enter T1 and approve a personalized review; enter G1-1 to see the report and send feedback; enter A1 for aggregate metrics. Repeat with a correct answer. The server records the state for the run through D1. All persisted communication is restricted to curated fictional phrases; submitted practice answers are graded but not stored. The Cloudflare deployment is serverless and has no persistent compute VM to shut down.

Limitations: no real identity federation, external LLM, email/SMS delivery, real minors, or production compliance claim. Cloud deployment, D1 integration, browser accessibility and judge acceptance must be separately evidenced.
